## 本次解析做了什么

1. **结构解析**：把 12 个 HTML（每个 400–950 KB，内含 CodeMirror 渲染的代码 DOM 与重复的辅助函数面板）还原为 12 份可搜索的 Markdown，去掉了渲染层、重复面板和 UI 文案。
2. **字幕利用**：把 2 份语音识别 JSON（3356 + 1723 条）转成逐句带时间戳的转录，并整理出 38 段时间轴、重点判断、现场演示、学员答疑与金句。
3. **知识梳理**：产出 4 份模块级详细摘要（12 个课时逐页拆解）+ 1 份讲解脉络摘要。
4. **建立索引**：文件索引、课时索引、章节索引、主题（概念→课时）索引、`helpers.*` API 索引、外部参考资料索引、录音→课时对照、缺口清单。
5. **写作总结**：`总结.md` 覆盖「这门课要回答什么问题 / 4 模块 11 课时逐页内容 / 知识主干 / 运行环境 / 三个最值得记的技术细节 / 录音额外收获 / 价值与短板 / 阅读路径 / 一页速查卡」。

## 重要提醒

- **交互单元离线跑不起来**：页面上的"运行"依赖课程主机中继与本地 NemoClaw 运行时。归档的可用价值是正文、代码清单、图示与讲解，不是可执行实验。
- **04c 深入探索缺页**：全课程统一参考文献表（`#refs`）因此不可读；如需补全应重新抓取 `04c-going-further.html`。
- **描述的是归档当时的内容**：模型路由为 `nvidia/nemotron-3.5-lightning-30b-a3b` / `nvidia/nemotron-3-embed-1b`，NemoClaw/OpenClaw/OpenShell 当时属预览或未开源状态，产品默认设置会变。
- **引用原文请回看 HTML**：提取算法会丢弃纯装饰性内联标签，个别句子可能缺一两个字。详见 `索引.md` 第 9.5 节。
