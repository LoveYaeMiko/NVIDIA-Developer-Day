# NVIDIA 开发者日 · 技术资料整理归档（2026-10-16 中国站）

本仓库是 **NVIDIA 开发者日（Developer Day）中国站 2026-10-16** 两场技术活动的个人学习整理与复盘成果：

- **主论坛 + 大模型训练与推理分会场**：96 张投影片照片 OCR + 现场录音转写，整理成讲义、讲稿对照、总结分析三份长文档。
- **智能体（Agent）培训**：12 个课程网页归档，提取为 12 份干净 Markdown，并配套总结、索引、模块摘要、字幕转录。
- **语音转文字工具链**：基于讯飞「录音文件转写大模型」的命令行工具与转写原始产物。

> 全部文本与图表均由原始音视频/照片派生而来；**原始音视频与图像源文件已从本仓库移除**（详见文末「关于删减」）。

## 处理流水线概览

```
4K 视频 + 现场录音 ──讯飞转写──> 转写结果/*.srt|md
投影片照片(96) ──OCR──> _build/ocr/text/*.txt
        │                      │
        └──按拍摄时刻对齐录音时间轴──> _build/notes/segNN.md
                                    └──> 讲义 / 总结 / 讲稿(md→html→pdf)

课程网页(12) ──结构解析──> 智能体培训摘要/课时全文/*.md ──> 总结 / 索引 / 附录
```

对齐思路：每张投影片照片都带有拍摄时刻，据此在该时刻附近的录音片段中截取讲解，从而把「页面文字」与「现场原话」逐页对齐。

## 关于删减（重要）

本仓库在发布前做了以下处理：

1. **移除全部音视频与图像源文件**：5 个 mp4（约 7.4 GB）、6 个 wav（约 8.0 GB）、259 张 jpg（约 464 MB），合计约 **15.9 GB**。仓库仅保留由它们派生的文本、结构化数据与 PDF 成果。
2. **移除凭证**：讯飞开放平台 AppID / APIKey / APISecret 所在的 `.env` 不入库，仅保留 `.env.example` 模板；文档中的示例凭证已替换为占位符。脚本内的 `SIGNATURE_VECTOR` 为官方文档公开的签名算法校验向量，用于自检，非真实密钥。
3. **移除本机信息**：文档与脚本中的本地绝对路径（含盘符、目录名、用户目录）已改写为**仓库相对路径**；Windows 用户目录名、机器标识、`desktop.ini`、`__pycache__` 等均未入库。
4. **Git 提交身份**使用 GitHub noreply 邮箱，不暴露个人邮箱。
5. 由于源文件缺席，文档中提及的 `IMG_20261016_*.jpg`、`录音机-*.wav`、`VID_*.mp4` 等原始文件**不在本仓库中**，仅保留其转写/OCR 派生文本。
