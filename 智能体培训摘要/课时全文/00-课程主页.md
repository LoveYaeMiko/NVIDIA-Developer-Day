# 使用 OpenShell 和 NemoClaw 构建安全智能体

## 摘要

现代智能体无处不在，其概念并不复杂：将模型连接到工具和记忆，再通过路由决策持续运行，直至完成任务。本课程将从零开始构建这样的系统，随后把这些理念与软件工程师和非技术用户都在使用的现代框架联系起来。您将从一次 API 调用起步，逐步学习智能体协作、有依据的检索、深度规划，以及如何使用 NVIDIA OpenClaw 和 NemoClaw™ 进行安全部署。

1

在下方确认模型路由。浏览器课程与本地智能体共用经过身份验证的课程中继。您可以选择目录中列出的任意兼容模型。

2

按照默认路径依次学习各模块，也可以直接跳转到您需要完成的任务。每个页面最后都会提供一个可直接运行的交互页面，其 JavaScript 代码也可供查看和修改。

3

在模块 3 和模块 4 中使用本地 NemoClaw 运行时。本 CPU 课程在 OpenShell 内启动 OpenClaw，并通过课程中继路由模型调用。打开服务即可检查各个界面。

## 学习目标

完成本课程后，学员将能够：

- 构建基本的智能体循环，并识别其核心组件。
- 在智能体系统中实现可靠的工具使用和函数调用。
- 使用结构化路由模式设计和协调多智能体系统。
- 使用 OpenShell 配置智能体身份，并确保智能体在沙箱中安全运行。
- 部署和管理自主智能体，同时构建持久化技能库。

*本地工作站环境中用于 OpenClaw 的 NemoClaw。来源：NVIDIA Build blueprint 卡片。*

**▸ 如何使用这些课时**

运行示例，检查输出，再修改一个输入并比较结果。每个单元格的代码控件都可显示 JavaScript；您可以先阅读和运行示例，再编辑代码。

点击章节标题或旁边的箭头，即可展开或折叠该章节。颜色用于辅助文字提示：蓝色表示信息，琥珀色表示注意事项，红色表示错误。请阅读文字，不要仅凭颜色判断。

使用章节查找章节。标题链接可以收藏或分享。提问时，助理可以参考当前章节。模型和会话控件是可选项；先围绕正在阅读的示例提问即可。

**▸ 模型请求失败时**

停止会取消当前请求。仅凭请求中止消息，无法判断原因是取消操作、页面跳转还是连接中断。请保留可见错误和已有的部分输出。超时表示在设定的等待时间内没有收到响应头或流式数据。

对于只读模型示例，请检查上方的模型访问配置，稍等后重新运行一次。如果再次失败，需要记录课时和章节链接、单元格标签、所选模型、错误文本及时间，以便诊断。切勿附上 API 密钥。再次运行会修改文件、安排任务或创建会话的工具或命令前，请确认第一次尝试是否已经完成了该操作。

遇到 HTTP 401 或 403，请检查凭据或访问权限。HTTP 429 表示服务正在限制请求，请等待后再试。5xx 响应可能表示提供方或中继服务出现故障。设置中的请求处理控制等待时间及流式传输开始前的可选重试。延长等待时间或增加重试次数无法修复无效凭据。请通过本页底部的支持链接报告持续发生的问题。
