    持续运行的智能体

    在模块 3b 中，您发送消息时智能体才会运行。心跳和 cron 任务可以启动无人值守的工作，智能体也可以将工作委派给子智能体。技能为运行中的智能体提供可复用的指令。每次运行仍使用智能体循环和 OpenShell 沙箱；会话、指令和触发条件决定运行的内容。您将安装一个技能，并观察一次由 cron 触发的写入。

    触发器如何选择上下文和指令

    本页中的每种机制都由以下三个参数描述：

    • 会话决定一次运行继承谁的上下文。
    • 指令通过文件或计划消息提供执行要求。
    • 触发器决定何时开始运行。

    下表展示了课程所用的配置。可以使用同样的三个字段对其它触发器类型进行分类；OpenClaw 还提供了其它会话模式。

    名称会话指令所在位置触发器
    技能（下方运行） 复用调用方的会话 workspace/skills/<name>/SKILL.md 本练习明确指定技能；自动选择须另行检查
    心跳（仅介绍概念） 此处为主会话 HEARTBEAT.md 网关计时器，默认约 30 分钟
    Cron （下方运行） 此处使用隔离会话；每次触发都会新建计划任务中的 payload.message 本练习指定的单次计划时间
    子智能体（仅介绍概念） 新建会话，父智能体持有句柄父智能体提供的任务指令父智能体在轮次进行期间决定
    OpenClaw 可以将 cron 任务绑定到主会话、独立会话、当前会话或指定名称的会话。本课程使用独立的 cron 运行，让每次演示都从空白会话开始。您将在本页运行技能和 cron 任务。Heartbeat 与子智能体任务分派仅作为表格条目介绍，本页没有单元会触发它们，因此无需等待它们运行。

    调度作业位于网关上，而不是某个 HTTP REST 路由之后。因此， Control UI 使用的同一个 WebSocket 连接，也是您通过 cron 方法 cron.list、cron.add 和 cron.remove 列出和管理这些作业的通道。cron 作业按照自身计时器触发，使持续运行的智能体无需人工介入即可执行操作。课程运行时会为本次演示创建隔离会话。如果连续性比隔离性更重要，OpenClaw 也可以将调度工作绑定到其它受支持的会话模式。

    cron 任务会在无人值守时运行。要求智能体“发送每日报告”的计划指令，无论您是否在观察都会触发。本课程为每次触发选择独立会话，因此不会自动沿用先前的消息历史。共享文件仍可能影响后续运行。其他 cron 配置可以保留或绑定会话上下文。模块 4a 将当前文件系统和网络策略与命令证据进行比较；配置的强制执行机制决定允许哪些操作。

    后续应用方向

    公开的 Hermes 代码库提供了相同的几类广泛能力：可复用技能、持久化记忆、计划任务和消息网关。其实现方式和默认设置与 OpenClaw 不同，因此应比较两者的安全边界和会话行为，而不能因为功能名称相同，就认定风险控制措施也相同。

    任何能够写入可复用指令、计划任务并接收远程消息的执行框架，都可能让受入侵指令在一次对话结束后继续存在。模块 4 会区分这些应用层控制与沙箱控制；后者用于限制文件系统、进程和网络访问。

    Hermes 会限制其消息入口。Hermes 的最新安全指南介绍了配对码，以及平台级或全局用户允许列表；没有匹配的允许规则时采用 default: deny。这些应用层控制决定谁可以与智能体通信。操作系统沙箱则另行限制其工具能够访问的资源。

    helpers.fetch(url, opts)浏览器原生的 fetch，保持原样公开，使节点可以直接调用任意 HTTP API 入口。参数和返回的 Response 与平台 API 完全相同。它不会重试，也不会附加密钥：上游服务不稳定时请使用 helpers.fetchRetry；模型、搜索或嵌入调用则优先使用上方的专用辅助函数，由它们自动添加路由和密钥。
    helpers.fetchRetry(url, opts)与 helpers.fetch 类似，并可接受一个有界的可选第三参数，例如 { retries: 2, timeoutMs: 120000 }。遇到 HTTP 429 时会遵循 Retry-After，其它情况下则报告最终的网络或 HTTP 结果。
    可启动实例终端
    helpers.terminal(cmd, {send, idleMs, totalMs, openMs, onChunk})通过可启动实例的 /ws/terminal WebSocket 打开 PTY 并运行 cmd。使用 "bash" 进入虚拟机 shell，或使用 "openshell sandbox connect <agent>" 进入受内核 sandbox 保护的智能体。send 是依次输入 PTY 的 shell 命令行数组，每行都会附加 Enter。绑定浏览器的会话保持直连；粘贴的访问会话会先尝试直连，再尝试获准的提供商专用中继。设置 relayWebSocket: true 可明确选择该恢复路由。返回 { output, raw, frames, exitCode, completion, transport }；output 已移除 ANSI 控制码，exitCode 是 PTY 返回的退出状态，未收到时为 null，transport 表示成功打开的直连或获准中继路由。completion 区分 exit、idle、deadline 和 disconnect；只有收到退出状态才能确认命令结束。Stop 会取消操作。可启动实例 URL 从 OpenClaw 探测结果中读取。仅适用于可启动实例。
    helpers.courseShell(helpers, command)在已连接的 sandbox 中执行命令，并要求退出状态为零。传入当前单元格的辅助函数以支持取消。返回终端文本；请重新读取文件以验证内容。

    helpers.evalSandboxNetwork({binary,host,port,method,path}, policy?)静态评估候选连接与 OpenShell 网络策略，返回 {action, matched, reason}，不发送网络请求。默认使用课程内置策略快照。先用 policyGet 读取实时策略，再传入评估函数；命令失败本身不能证明是哪种机制拒绝了访问。
