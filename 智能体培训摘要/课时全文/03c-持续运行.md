# 持续运行的智能体

在模块 3b 中，您发送消息时智能体才会运行。心跳和cron任务可以启动无人值守的工作，智能体也可以将工作委派给子智能体。技能为运行中的智能体提供可复用的指令。每次运行仍使用智能体循环和 OpenShell 沙箱；会话、指令和触发条件决定运行的内容。您将安装一个技能，并观察一次由 cron 触发的写入。

## 触发器如何选择上下文和指令

本页中的每种机制都由以下三个参数描述：

- 会话决定一次运行继承谁的上下文。
- 指令通过文件或计划消息提供执行要求。
- 触发器决定何时开始运行。

下表展示了课程所用的配置。可以使用同样的三个字段对其它触发器类型进行分类；OpenClaw 还提供了其它会话模式。

| 名称 | 会话 | 指令所在位置 | 触发器 |
|---|---|---|---|
| 技能（下方运行） | 复用调用方的会话 | workspace/skills/<name>/SKILL.md | 本练习明确指定技能；自动选择须另行检查 |
| 心跳（仅介绍概念） | 此处为主会话 | HEARTBEAT.md | 网关计时器，默认约 30 分钟 |
| Cron （下方运行） | 此处使用隔离会话；每次触发都会新建 | 计划任务中的 payload.message | 本练习指定的单次计划时间 |
| 子智能体（仅介绍概念） | 新建会话，父智能体持有句柄 | 父智能体提供的任务指令 | 父智能体在轮次进行期间决定 |

OpenClaw 可以将 cron 任务绑定到

主会话、独立会话、当前会话或指定名称的会话

。本课程使用独立的 cron 运行，让每次演示都从空白会话开始。您将在本页运行技能和 cron 任务。Heartbeat 与子智能体任务分派仅作为表格条目介绍，本页没有单元会触发它们，因此无需等待它们运行。

## 第 2 步 · 检查正在运行的智能体

调度作业位于网关上，而不是某个 HTTP REST 路由之后。因此， Control UI 使用的同一个 WebSocket 连接，也是您通过 cron 方法cron.list、cron.add和cron.remove列出和管理这些作业的通道。cron 作业按照自身计时器触发，使持续运行的智能体无需人工介入即可执行操作。课程运行时会为本次演示创建隔离会话。如果连续性比隔离性更重要，OpenClaw 也可以将调度工作绑定到其它受支持的会话模式。

此单元会安装一项具有唯一名称的任务，并等待最多三分钟，确认计划执行成功。这项单次任务会要求在执行后自动删除，因此关闭页面后的工作也能受到限制。单元会验证新的文件参考码，并移除自己创建的任务，包括失败或按下“停止”时。请保持页面打开，直到清理完成。若清理失败，请保留记录中的任务 ID，并使用移除单元。证据文件会保留供您检查。

cron 任务会在无人值守时运行。

要求智能体“发送每日报告”的计划指令，无论您是否在观察都会触发。本课程为每次触发选择独立会话，因此不会自动沿用先前的消息历史。共享文件仍可能影响后续运行。其他 cron 配置可以保留或绑定会话上下文。模块 4a 将当前文件系统和网络策略与命令证据进行比较；配置的强制执行机制决定允许哪些操作。

## 后续应用方向

公开的Hermes代码库提供了相同的几类广泛能力：可复用技能、持久化记忆、计划任务和消息网关。其实现方式和默认设置与 OpenClaw 不同，因此应比较两者的安全边界和会话行为，而不能因为功能名称相同，就认定风险控制措施也相同。

任何能够写入可复用指令、计划任务并接收远程消息的执行框架，都可能让受入侵指令在一次对话结束后继续存在。模块 4 会区分这些应用层控制与沙箱控制；后者用于限制文件系统、进程和网络访问。

Hermes 会限制其消息入口。

Hermes 的

最新安全指南

介绍了配对码，以及平台级或全局用户允许列表；没有匹配的允许规则时采用

default: deny

。这些应用层控制决定谁可以与智能体通信。操作系统沙箱则另行限制其工具能够访问的资源。

以下参考资料介绍了保存可复用代码、执行状态或指令的不同方法：

- Wang et al., Voyager (2023)。这一理念的研究起源，通过 Minecraft 智能体得到演示。
- LangGraph Persistence。利用带检查点的图实现保存和恢复。
- Anthropic, Agent Skills。面向生产环境的技能文件夹布局。

### 参考资料

- Wang et al., Voyager: An Open-Ended Embodied Agent (2023)。本页所基于的技能库和记忆化轨迹机制，该论文通过 Minecraft 智能体进行了演示。
- Park et al., Generative Agents (2023)。多日自主智能体模拟；持续运行的循环会复用其中的反思和记忆整合模式。

- Hermes Agent。一种智能体应用，具有可自我改进的技能、持久化记忆、cron 和消息网关；NVIDIA 的 DGX Spark 操作手册将 Hermes 和 NemoClaw 列为不同的设置路径。
